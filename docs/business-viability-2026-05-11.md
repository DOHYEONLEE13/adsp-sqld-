## 🧠 Premise Challenge — 진짜 풀어야 할 문제는?

사용자가 던진 질문: "이 사이트가 사업적으로 가치가 있는가?"

이 질문의 framing 자체를 challenge:

| 표면 질문 | 진짜 질문 (CEO framing) |
|---|---|
| "사업 가치가 있는가?" | "이 시간/노력의 **기회비용**을 정당화하는가?" |
| "수익이 가능한가?" | "솔로 개발자가 **번아웃 전에** 명확한 신호 (월 ARR 1천만원+)를 얻을 수 있는가?" |
| "제품이 좋은가?" | "**돈을 낼 사람**이 누구이고 **왜 지금** 사야 하는가?" |
| "경쟁사 대비 어떤가?" | "에듀윌이 6개월 내 같은 가격대 진입 시 **어떻게 살아남는가**?" |

**Bezos regret-minimization**: 80세에 돌아봤을 때 "이거 안 했어서 후회"인가, "이거 6개월 더 했어서 후회"인가? → 답이 분명하면 결정도 분명.

이 보고서는 표면 질문이 아니라 **진짜 질문들**에 답합니다.

## 📊 1. 시장 사이즈 (TAM/SAM/SOM)

### 응시자 = 학습 시장 baseline

| 자격증 | 연 응시자 (2025) | 합격률 | 학습자 추정 (1.5~2x 응시자) |
|---|---|---|---|
| ADsP | **72,708명** | 67.26% ([alljungbo001](https://www.alljungbo001.co.kr/2026/01/2026-adsp.html)) | 110K~145K |
| SQLD | 추정 30~50K | 약 50% ([codeit.kr](https://www.codeit.kr/articles/dataCertificate)) | 45K~100K |
| **합산** | **~120K** | — | **~155K~245K/연** |

> KDATA 공식 SQLD 응시자 통계는 공개 어려움. 50K로 추정 (5년 추세 + 2025년 4회 시행).

### TAM / SAM / SOM 계산

```
TAM (이론 최대 시장)
  = 200K 연 학습자 × 평균 ARPU 5만원 (책+강의 평균)
  = 100억원/연

SAM (디지털 학습 앱 카테고리 도달 가능)
  = TAM × 5% (앱 학습 채택률 추정 — 한국 EdTech 평균)
  = 5억원/연

SOM (현실적 점유 — 1년 차)
  = SAM × 5~15% (신생 브랜드, 마케팅 자본 0)
  = 2,500만원~7,500만원/연
  = 월 200~600만원
```

> **중요**: ADsP/SQLD 학습 앱 검색 시 **모바일 앱 리뷰 결과 0건** 발견. 카테고리 자체가 비어있음 → blue ocean signal.

### 시장 성장률
- ADsP 합격자: 2022 **63%** → 2023 **64%** → 2025 **67%** → **응시자 증가 + 합격률 안정** = 성숙기 진입
- SQLD: "매년 응시 인원 증가 추세" ([lifelearn.kr](https://lifelearn.kr/blog/0102-sqld-certification-exam-schedule-guide/))
- 데이터 직무 채용 → SQL/통계 가산점 → 자격증 수요 견조

**Verdict**: 시장은 작지 않다. 성장 중. 학습 앱 카테고리는 비어있음. 진입 정당성 ✅

## 💡 3. PMF (Product-Market Fit) 신호 — 현재는 약함

### PMF 강한 신호 (Sean Ellis 기준)
- "이 제품이 없으면 매우 실망할 것" 응답률 ≥40% → 현재 측정 불가 (사용자 베이스 없음)
- 입소문 (월 자연 유입 30%+) → **GA4 갓 활성화**, 데이터 0
- 재구독률 ≥60% → 결제 미활성

### PMF 신호 추론 (사용 가능한 간접 데이터)

| 신호 | 상태 | 점수 |
|---|---|---|
| 콘텐츠 완성도 | 225 step + 631 문항, mechanical 결함 0 (audit 통과) | ✅ 8/10 |
| UX 품질 | 모바일 우선, 게임화 (우주 RPG 비유), 보안 감사 A- | ✅ 8/10 |
| 정량 사용 데이터 | DAU/WAU/Retention 측정 인프라 (GA4) **방금 활성** | ❌ 0/10 |
| 정성 피드백 | 사용자 리뷰·후기 0건 | ❌ 0/10 |
| 결제 데이터 | 토스 심사 대기 중, 0 매출 | ❌ 0/10 |
| Organic search | Sitemap 989 URL 등록, **색인 대기 중** | 🟡 2/10 |

**Verdict**: PMF는 **아직 증명되지 않음**. 인프라는 깔렸지만 데이터 0.
다음 90일이 PMF 증명 결정 시점.

## 💰 4. Business Model Viability — 단위 경제

### 현 가격 정책

```
무료     0원         ⚡ 10/30분 충전, 광고
1주 단기  ₩4,900     7일 무제한
월 구독   ₩9,900     무제한 + 자동 갱신
```

### 단위 경제 추정 (월 구독 기준)

| 항목 | 값 | 출처/계산 |
|---|---|---|
| ARPU (월 평균) | **₩7,000** | 9.9K × 70% (할인/단기 mix) |
| 평균 사용 기간 | **3개월** | 자격증 학습 전형 (시험 전 1~3개월) |
| **LTV** | **₩21,000** | 7K × 3개월 |
| 결제 PG 수수료 | -₩630 (3%) | 토스 디지털 콘텐츠 |
| Supabase 인프라 | -₩200 | $0.0046/MAU (대략) |
| 마케팅 외 변동비 | -₩830 | |
| **GP per user** | **~₩20,170** | 96% gross margin |
| 목표 CAC | **≤₩7,000** | LTV/CAC ≥ 3 (SaaS 표준) |

### 손익분기점 시나리오

```
고정비 (월) — 최소화:
  Cloudflare Pages          ₩0      (무료 티어)
  Supabase Pro              ₩30K    ($25)
  도메인·기타                ₩10K
  사업자 통장 수수료          ₩0~5K
  ───────────────────────────────
  TOTAL                    ~₩45K/월

손익분기 사용자 수:
  45K (고정비) ÷ 20K (GP/user) = 약 2.3 users/월
  
누적 활성 구독자 (3개월 평균 이용 가정):
  손익분기 = 약 7명
```

→ 손익분기 진입은 매우 낮음. **Cash flow 자체는 1개월 내 가능**.

### 의미 있는 매출 시나리오

```
시나리오 A — 비관 (PMF 약함, 마케팅 X):
  월 100명 가입, 70명 결제 → 월 매출 ₩70만 → 연 ARR ₩840만
  
시나리오 B — 현실 (블로그 SEO + 입소문):
  월 500명 가입, 350명 결제 → 월 매출 ₩350만 → 연 ARR ₩4,200만
  
시나리오 C — 낙관 (인플루언서 협업 + 합격수기):
  월 2,000명 가입, 1,400명 결제 → 월 매출 ₩1,400만 → 연 ARR ₩1.68억
```

> **Founder break-even** (전업 가능 시점): 월 매출 ₩300~500만 = 시나리오 B 도달 시.

**Verdict**: 단위 경제는 **매우 우수** (96% gross margin). 문제는 **CAC**.

## ⚠️ 6. 위험 5개 (Munger Inversion — "어떻게 실패할 수 있는가?")

### R1. 콘텐츠 저작권 분쟁 (CRITICAL · One-way door)

- **위험**: 기출문제 활용 + 해설 — KDATA가 저작권 주장 시 서비스 중단 가능
- **현재 mitigation**: CLAUDE.md §2 절대 원칙 #1 (PDF 복붙 금지, 오리지널 카피)
- **잔여 위험**: 기출문제 자체 (질문/보기) 인용 — 한국 저작권법 "공표된 저작물 인용" 적용 가능하나 회색 영역
- **대응**: KDATA에 사전 라이선스 문의 (월 ₩50K 수준이면 정당)

### R2. 에듀윌 squeeze (HIGH · 6~12개월 내)

- **위험**: 에듀윌이 모바일 앱 출시 + 가격 ₩9,900 매칭 → 자본력으로 1개월 내 점유
- **현재 mitigation**: 게임화 차별화, 콘텐츠 깊이, 1년치 베이스 선점
- **대응**: 빠른 사용자 베이스 확보 + 사용자 lock-in (학습 진도 + 친구 시스템)

### R3. CAC > LTV (HIGH · 검증 필요)

- **위험**: 광고 없이 SEO + 입소문만으로는 사용자 도달 X. 결국 광고비 = LTV(₩21K) 초과
- **현재 mitigation**: SEO 인프라 깔림, 블로그 6개
- **대응**: 90일 GTM 실험으로 채널별 CAC 측정. CAC > ₩7K 채널은 즉시 중단.

### R4. Solo dev burnout (MEDIUM · 6~12개월 내)

- **위험**: 1인 운영 + CS + 콘텐츠 + 코드 + 마케팅 = 80h/주 → 6개월 내 burnout
- **현재 mitigation**: AI 도구 활용 (Claude/Codex), 자동화 인프라
- **대응**: 월 매출 ₩200만 도달 시 CS 일부 외주 (₩30~50K/월)

### R5. 시험 출제 트렌드 변화 (LOW · 매년)

- **위험**: KDATA가 출제 범위/형식 대폭 변경 → 콘텐츠 재작성 부담
- **현재 mitigation**: 토픽 정규화 (`topicAlias.ts`)로 콘텐츠 모듈화
- **대응**: 매년 출제 안내 모니터링 + 분기당 1회 콘텐츠 audit

### Final framing

QuestDP는 **"가능한 사업"** 입니다. **"확실한 사업"** 은 아직 아닙니다.

차이는:
- 가능한 사업 = 시장 ✓ + 제품 ✓ + 비즈니스 모델 ✓ → 0매출에서 100매출까지 가는 길은 명확하나 검증 안 됨
- 확실한 사업 = 위 3개 + **재구매 데이터** + **CAC 검증** + **organic growth signal**

향후 **90일이 결정적**. 그 안에:
- 첫 50명 결제자 확보
- 1개 GTM 채널의 CAC < ₩7,000 검증
- 첫 합격수기 1건 (organic)

이 셋 중 **2개 이상 달성** 시 → 시나리오 B 진입, 전업 가능.
**1개 이하** 시 → 사이드 유지 또는 종료 검토.

### 사용자 시간의 기회비용

솔로 개발자가 80h/주 투입할 때 기회비용:
- 시급 ₩50K 가정: 월 1,600만원

QuestDP가 12개월 후 ₩4,800만 ARR 못 만들면 **순현금 손실**. 시나리오 A는 break-even 미달.
