TITLE: SQLD 노랭이와 QuestDP — 언제 무엇을 보면 좋을까

PRIMARY KEYWORD: SQLD 노랭이

BODY:
SQLD의 ‘노랭이’로 불리는 **SQL 자격검정 실전문제**는 공부한 내용을 문제로 점검할 때 쓰는 자료입니다. 처음 펼쳤는데 해설까지 낯설다면 실력이 없어서가 아니라, 문제를 읽는 데 필요한 개념을 아직 배우지 않았을 수 있습니다. 개념을 짧게 익히고 같은 범위를 푼 뒤, 틀린 이유를 다시 확인하는 순서로 연결해 보세요.

## 문제집과 실제 기출 원문은 구분하기

노랭이를 ‘회차별 50문항 기출집’으로 생각하고 일정을 짜면 목차와 공부 계획이 맞지 않을 수 있습니다. 구입한 판본에서 SQLD와 SQLP 대상 범위, 목차, 정오표를 먼저 확인하세요. 인터넷 자료의 ‘기출’이라는 이름도 공식 공개문제, 복원문제, 예상문제 중 무엇을 뜻하는지 확인해야 합니다.

교재 문항을 QuestDP가 그대로 제공한다는 뜻도 아닙니다. 같은 개념을 서로 다른 예제에 적용하는 데 두 자료를 쓰는 것입니다. 교재의 문제·해설을 스캔해 공유하지 말고, 자신의 틀린 이유와 문제 위치만 메모하세요.

## 해설을 읽어도 막힐 때 돌아갈 곳

| 막히는 부분 | 먼저 할 일 | 다시 풀 때 확인 |
| --- | --- | --- |
| 단어 자체가 낯설다 | 입문 설명이나 강의에서 용어와 작은 예시 보기 | 문제에서 어떤 대상을 묻는지 말하기 |
| 문법은 알지만 결과를 못 고른다 | 작은 표에 행을 적고 조건 적용 전후 비교 | 어떤 행이 남고 무엇이 계산되는지 설명 |
| 답을 외운 것 같다 | 정답을 가리고 선택 이유와 다른 선택지의 차이 말하기 | 조건이나 데이터가 바뀌어도 설명되는지 확인 |

예를 들어 주문표에 라떼 2건과 차 1건이 있을 때 ‘라떼만 보기’는 2건을 남기는 일입니다. 라떼 주문 수를 세는 것은 그 2건을 하나의 숫자로 요약하는 일이고요. 표의 행을 먼저 적어보면 낯선 SQL 문법을 읽을 때도 무엇을 하려는지 놓치지 않을 수 있습니다.

## 강의 직후, 같은 범위를 문제로 확인하기

입문 강의로 시작한다면 아답터 등 선택한 강의의 현재 공개 목록과 교재 범위를 직접 맞춰보세요. 전체 영상을 한 번에 끝내고 문제집을 여는 대신, 한 범위를 들은 직후 [QuestDP SQLD 개념·예제](/curriculum/sqld/)로 짧게 확인한 다음 해당 범위의 노랭이를 푸는 방식입니다. 강의 제공 범위와 무료 여부를 일괄 보장하지는 않습니다.

그날 틀린 문제는 ‘JOIN이 어렵다’보다 ‘연결되는 항목이 두 개면 결과 행도 늘어날 수 있다는 것을 놓쳤다’처럼 적습니다. JOIN은 표끼리 관련된 정보를 연결하는 방법입니다. 아직 배우기 전이라면 이름을 외우기보다 주문과 고객을 연결하는 작은 예시부터 보면 됩니다.

## 4주 예시: 문제집 2회독을 마지막에 몰아 넣지 않기

| 기간 | 주된 범위 | 문제집과 복습 |
| --- | --- | --- |
| 1주 | 1과목 데이터 모델링 | 배운 범위 문제를 당일 풀고 다음날 오답 확인 |
| 2주 | 2과목 SQL 기본 | 조건·함수·묶음 계산을 작은 표로 확인하며 1회독 |
| 3주 | 2과목 활용·관리 | 표 연결과 하위 질의 등 남은 범위 1회독 마무리 |
| 4주 | 전 범위 문제집 2회독·오답 | 답을 가리고 재풀이, 설명 못 한 문제 우선 보완 |

2회독은 책장을 두 번 넘겼다는 뜻이 아닙니다. 맞혔어도 이유를 설명하지 못한 문제는 다시 볼 대상으로 남깁니다. 풀이량이 계획보다 많다면 기간을 늘리거나 하루 범위를 조정하세요. 4주와 2회독은 실행 예시이지 누구에게나 충분한 합격 기준은 아닙니다.

## 노트는 길게 베끼지 말고 다음 풀이를 준비하기

한 줄 기록 예시는 ‘문제 위치 / 내가 놓친 조건 / 다음에 먼저 볼 것’입니다. 가령 ‘SQL 기본 00번 / NULL을 0처럼 봄 / 값이 없는 것과 숫자 0을 분리’처럼 씁니다. 해설을 통째 옮기면 기록은 길어져도 내 판단의 오류는 드러나지 않을 수 있습니다.

전체 시험 범위는 [KDATA SQLD 안내](https://www.dataq.or.kr/www/sub/a_04.do), 전체 일정 배분은 [SQLD 4주 공부법](/blog/sqld-공부법/)에서 이어 확인할 수 있습니다. QuestDP는 짧은 개념 확인과 예제·복습에 쓰고, 실제 SQL 실행이 필요하면 별도의 SQL 실행 환경에서 연습하세요.

## 자주 묻는 질문

### 노랭이가 공식 회차별 기출문제집인가요?

이 글은 SQL 자격검정 실전문제를 회차별 기출 원문집으로 취급하지 않습니다. 구입한 판본의 목차·대상 범위·정오표를 확인하고, 복원문제나 예상문제와도 구분하세요.

### 노랭이 2회독이면 합격할 수 있나요?

회독 횟수만으로 합격을 판단할 수 없습니다. 정답을 가린 재풀이에서 이유를 설명하고, 시간 제한이 있는 별도 모의 문제에서도 적용할 수 있는지 점검해야 합니다.

### QuestDP에서 노랭이 문제를 그대로 풀 수 있나요?

그렇게 안내하지 않습니다. QuestDP의 개념과 자체 학습 예제로 같은 범위를 확인한 뒤, 소유한 문제집에서 다른 예제를 푸는 병행 흐름입니다.
